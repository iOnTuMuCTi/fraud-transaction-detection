# Выявление мошеннических финансовых транзакций

Исследовательский ML-проект по бинарной классификации финансовых операций. В работе объединены разведочный анализ, построение поведенческих и транзакционных признаков, подбор гиперпараметров через Optuna и сравнение нескольких моделей и ансамблей.

Проект сопровождает статья **«Выявление мошеннических транзакций на основе поведенческих и транзакционных признаков финансовых операций»** (Д. А. Антипенко, М. Е. Суханов, В. Ю. Радыгин, 2026).

## Что исследуется

- исходный набор: 50 000 операций и 25 полей;
- целевой класс: `Fraud_Label` (`Fraud` / `Normal`);
- после удаления четырёх строк без целевой метки: 49 996 наблюдений;
- мошеннические операции: 2 423, около 4,85%;
- ключевая метрика: ROC-AUC; дополнительно оцениваются Precision, Recall и F1 для класса мошенничества.

В статье подтверждены две прикладные гипотезы: доля мошенничества выше у международных операций (около 6,1% против 3,5%) и у операций в необычное время (около 6,1% против 3,6%).

## Реализованный ML-процесс

1. Проверка схемы и подготовка целевой метки.
2. Создание временных, относительных, географических и комбинированных признаков риска.
3. Стратифицированное разбиение train/test.
4. Раздельная обработка числовых и категориальных признаков.
5. Кросс-валидация полных `Pipeline`, чтобы препроцессинг обучался только внутри каждого фолда.
6. Optuna-подбор для Logistic Regression, Random Forest и HistGradientBoosting.
7. Сравнение отдельных моделей, soft voting и stacking.
8. Анализ важности признаков и построение ROC-кривых.

## Данные

CSV не включён в репозиторий. Исходный `FraudShield_Banking_Data.csv` распространялся через Kaggle-набор `algozee/financial-transaction-fraud-dataset`, который на 4 сентября 2026 года недоступен публично. Подробности и ожидаемая схема приведены в [`data/README.md`](data/README.md).

Не следует подменять его набором `ziya07/financial-transaction-dataset-for-risk-prediction`: у него другое имя файла, другая схема и 10 000 строк, поэтому результаты статьи с ним невоспроизводимы.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Поместите исходный файл в data/
python scripts/validate_dataset.py data/FraudShield_Banking_Data.csv
jupyter lab notebooks/fraud_detection.ipynb
```

В Windows окружение активируется командой `.venv\Scripts\activate`.

Путь к CSV можно передать без копирования файла:

```bash
export FRAUD_DATA_PATH=/absolute/path/to/FraudShield_Banking_Data.csv
jupyter lab notebooks/fraud_detection.ipynb
```

По умолчанию Optuna выполняет 15 испытаний на модель. Для режима, использованного в исходном исследовании:

```bash
export FRAUD_N_TRIALS=40
```
